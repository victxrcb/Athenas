# F3 — Git, MCP e Skills

## Entregue

- Git do projeto ativo: status, stage/unstage, commit, branches, diff lado a lado e lista/criação de worktrees via CLI.
- MCP: leitura das configurações Claude (`~/.claude.json`, `.mcp.json` do projeto) e Codex (`~/.codex/config.toml`), lista de servidores por agente, edição do arquivo local com validação JSON/TOML, backup e substituição atômica.
