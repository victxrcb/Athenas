# F0 — validação

## Entregue

- Scaffold Tauri 2, React 18, TypeScript estrito, Vite e Zustand.
- Barra de janela personalizada e seletor nativo de pasta.
- Home em português com saudação, caixa de comando, atalhos, recentes vazios e arte ASCII gerada em build.
- Logo circular, favicon e ícones Tauri gerados da arte indicada.
- Modal de nova sessão. O formulário informa que a abertura real ainda não está disponível nesta versão.

## Verificações em 11/11/2026

- `npm.cmd run build`: passou; JavaScript principal 181,68 kB (55,96 kB gzip), CSS 15,35 kB.
- `npm.cmd test`: passou, 1 teste.
- `npm.cmd run e2e`: a asserção passou no Microsoft Edge; o processo do runner não encerrou automaticamente no ambiente e foi interrompido após o resultado.
- `cargo fmt --check`: passou.
- `cargo test` e `npm.cmd run app`: não validados; Cargo não conseguiu conectar ao crates.io para obter Tauri.
- `npm.cmd audit`: endpoint de advisories indisponível. `npm install` reportou 4 avisos (1 moderado, 1 alto, 2 críticos), ainda sem diagnóstico confiável.

## Metas de desempenho

Instalador, tempo de abertura e RAM ociosa dependem do build nativo. Sem dependências Rust disponíveis, ainda não há medição válida. A entrega está abaixo da fase de PTY, então throttle e cinco terminais também não se aplicam.
